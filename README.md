# Roblox Teleport Script

This script allows players to teleport to specific locations in a Roblox game. The script is placed in a Script object within the ServerScriptService. It provides a user-friendly interface for players to select and teleport to predefined locations, enhancing the game's navigation and player experience.

## Installation

1. Open Roblox Studio.
2. Create a new Script object in the ServerScriptService.
3. Copy and paste the contents of `TeleportScript.server.lua` into the Script object.

## Use

1. Players will receive a teleport tool when they join the game.
2. Equip the teleport tool to open the teleport GUI.
3. Click on the desired location button to teleport to that location.
